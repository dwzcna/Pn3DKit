# 外部参照同名块检查

在 Bind 对话框选择 **Insert（插入）** 合并之前，执行 `XREFBLOCKCHECK`，或使用 **Pn3D工具箱 → 图纸操作 → 外部参照检查块冲突**。

只需 AutoCAD 2026 的活动图纸，不要求 Plant 项目。命令不绑定、不插入、不改名、不重载，也不保存源图。

## 操作与结果

1. 统一确认日志目录。FILEDIA=1 时显示 `输出日志目录<…> 或 [选择..(C)]:`，回车采用建议路径，C 打开文件夹选择器；FILEDIA=0 时输入目录。
2. 读取主图、全部直接外参以及沿附着传播的嵌套外参。根层覆盖纳入，嵌套覆盖边界单独记录。已加载数据采用宿主当前数据库，未加载文件旁路只读读取。
3. 比较同名定义，命令行列出前 20 个冲突块及来源，完整分组和差异写入报告。可以按 Esc 中断。
4. 最后选择是否保留日志。全部完整且正常时默认 N；存在冲突、不完整、读取错误或中断时默认 Y。切换或关闭原图后停止，无法安全询问时保留。

例如 A.dwg、a2.dwg 的 Valve 相同，a1.dwg 的 Valve 不同，报告将它们分成两组；主图没有 Valve 时，两个外参之间不同也会报告冲突。

| 状态 | 含义 |
| --- | --- |
| 一致 | 所有已纳入来源完整读取，同名定义内容相同 |
| 冲突 | 已确认至少两种不同定义；其他来源未读完时同时注明无法完整比较 |
| 无同名定义，无需比较 | 完整范围内仅一个来源含该命名定义 |
| 无法完整比较 | 范围、实体、资源或依赖未能可靠读取／解释，不能判定一致 |
| 读取错误 | 定义读取失败，保留可获得的 SDK 错误和来源 |

主图已有但尚未插入的命名块也参与检查。清单分别记录直接引用数和模型／布局可达的使用状态；未使用定义不冒充正在使用。相同来源保留全部引用链，同路径不同宿主状态不合并。

## 比较内容及限制

- 比较块基点、单位、使用相关标志、几何参数、文字、属性定义、显示资源与递归嵌套定义。顶层 Valve 的实例位置、旋转、比例和实例属性不属于 Valve 定义内容。
- 忽略句柄、ObjectId 和定位路径。实体按多重集比较，保留重复数量；显式绘制顺序单独记录。默认顺序可能影响遮挡而无法可靠排除时标记不完整。数值不取整、不设容差。
- 图层、线型、字体和标注样式读取语义属性，排除来源的外参依赖／使用缓存标志。必要资源无法读取时标记不完整；文件摘要相同后仍核对完整内容。
- 动态块追溯原始命名定义，匿名块按所属关系处理；读取内部引用的动态值和可访问的字典、参数／动作关联。**原生 EvalGraph 及未解释的动态节点不会判为完整。**
- 约束读取公开关联、节点类型及几何参数，节点编号只用于连接。**约束子实体路径和专有参数尚未完整规范化。**
- Solid3d／Region 读取 BRep 顶点、边、环、面、壳、连通体及支持的精确解析／NURBS 参数；不以体积、包围框、三角化或原始 ACIS 字节判断相同。**未知几何、曲面 UV 修剪及 Surface 子实体外观仍可能不完整。**
- SubDMesh 读取顶点、面连接及可读逐顶点数据，内部索引转为拓扑关联。**网格棱折、子实体材质及旧式网格的部分语义仍不完整。**
- 代理对象报告原始类名。未知二进制、未支持类型、未确认命名空间、循环外参和视口图层覆盖均明确说明原因。

报告反映定义差异与合并风险，不承诺精确模拟所有对象的最终 Bind → Insert 结果。“未使用定义”不等于一定会被合并。

## 日志

建议目录：`文档\Pn3DKit\XrefBlockCheck\yyMMddHHmmss`，重名追加 `_01` 等序号。已有同名报告时重新选择目录，不覆盖。

- `XrefBlockCheck.log`：运行参数、外参关系、来源读取方式、完整定义清单、内容分组、差异及结束汇总。
- `XrefBlockCheck.csv`：UTF-8 BOM，列为块名、状态、定义分组、来源图纸、引用链、使用情况、差异及错误详情。每个来源／引用链单独一行。

两文件逐条刷新。取消或错误后保留已经完成的记录，未完成的部分不会显示为无冲突。

本版执行构建、离线快照和宿主替身验证；真实 CAD 数据、动态行为、绘制顺序及绑定对照仍需使用授权测试图纸复测。
