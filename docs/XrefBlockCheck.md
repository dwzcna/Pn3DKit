# 外部参照块名称统计与二维显示比较

`XREFBLOCKCHECK` 首先保留全部名称统计，再比较跨来源同名普通块。只需当前 AutoCAD 图纸，不要求 Plant 项目。Ribbon 入口保持“图纸操作 → 外部参照块名称统计”。

## 来源与名称输出

主图、直接附着／覆盖外参及可传播的嵌套附着关系纳入，嵌套覆盖边界记录为未纳入。包括未插入命名块和匿名块，排除模型／布局空间及外参容器。已加载外参使用宿主当前数据库，未加载文件旁路只读读取，不成为打开的 CAD 文档；只释放工具创建的数据库。

完整 BlockTableId 区分来源；同源多链只扫描一次，同路径不同宿主状态分别保留。通过已确认命名空间恢复原名，不截取最后一个竖线。缺失、循环、原名无法确认及读取失败明确标记范围不完整。

来源发现阶段先按现有附着／覆盖规则只读取外参关系元数据，完整确定已确认来源清单；该阶段不读取普通块名称或实体内容、不创建逐图名称 CSV。随后按主图优先的发现顺序扫描名称，分母固定，同源多链不重复计数；同路径不同宿主状态分别计数。缺失来源单独报错，数量仅代表已确认范围。

每张图进入名称扫描时立即创建 `图纸名__完整GUID.csv`，在该阶段读取块表前刷新两列表头“块名称、是否匿名”，确认一个名称就写入，每 50 行或首个待刷新名称满 1 秒刷新。定时器只访问文件缓冲；结束最终刷新关闭。来源数据库复用，正常情况下关系和名称阶段各枚举一次块表，不重复装载源文件。两阶段之间的来源身份、文件状态或外参关系变化时停止。

`XrefBlockSources.csv` 保持以下结构：

```csv
dwgNo,来源ID,来源编号,来源图纸,数据来源,名称清单文件,扫描状态,已输出数量,已刷新数量,耗时毫秒,详情
```

dwgNo 每次从主图 1 开始，按首次扫描顺序递增。开始／结束历史复用编号，不按引用链增加计数。完整路径、GUID、数据来源、清单映射、数量和耗时可追溯；后续发现的链补入 LOG。

`AnonymousBlockStatus.csv` 与 `NormalBlockStatus.csv` 继续包含全部名称：

```csv
块名称,dwgNo,dwg计数
Valve,1/2/5,3
Pump,2,1
```

按 SDK 匿名标志分表，名称使用 OrdinalIgnoreCase，编号去重后数字升序以 / 连接；dwg计数是不同来源数据库数，不是插入数或引用链数。单来源名称也输出。

## 命令行输入与进度

比较时显示“正在对比块 1/8 Valve ...”，每组报告刷新成功后即时输出“块 Valve 符合／不符合／未验证”。约每 3 秒心跳显示当前文件、块或阶段。开始和结束展示日志路径之前均提醒：“文件较多或块较多时，耗时可能比较长，长按ESC键中断处理过程”。

六类批次目录输入统一：FILEDIA=0 直接输入路径，回车采用建议目录；FILEDIA=1 先显示建议目录，回车采用，输入或点击“选择..(C)”才打开系统文件夹选择器。取消结束，不创建日志；原图纸或项目变化时停止。

```text
正在发现外参文件……已发现 3 个来源
扫描文件 1/3 A.dwg ...
正在对比块 1/8 Valve ...
块 Valve 符合
块 Pump 不符合
块 Instrument 未验证
```

图纸序号对应名称扫描顺序及 dwgNo，块序号按候选名称组计数。发生输出故障时不显示该组成功完成；中断后未执行的候选输出未验证。发现阶段中断保留已发现关系，名称阶段中断保留已确认名称，未扫描来源在 LOG 中列明，不冒充空图纸。

## 候选内容比较

两份名称统计先刷新到文件，再从同一批内存中筛选非匿名且 dwg计数大于 1 的候选，不回读 CSV。只有候选才建立准备层和专用图形设备，不创建旧字段快照读取器，不查询插入数量。必要的普通和匿名子块随命名父块处理。

仅为跨来源候选和必要依赖建立隔离临时数据库，以原点、零旋转、单位比例按块基点放置；固定 WCS 俯视正交、同组公共视窗、2048×2048 和深浅双背景。比较完整彩色像素及有效颜色、透明度、线宽，多线宽增加公共编码图核对位置；直线与等效折线可匹配，句柄、内部图层名及顶层已有插入参数不参与。顶层属性用定义默认值，内部嵌套属性用已有值。代表图像无损压缩，摘要相同后仍完整回读核对；不同内容组生成 VisualDiff__完整GUID__G1-Gn.png，并与日志统一保留或清理。

XrefBlockVisualPreparation 使用 WblockCloneObjects 和独立临时库复制定义与资源，Replace 防止默认同名资源误合并。按实例落实 ByLayer／ByBlock／默认外观，打开和解冻临时层。使用 ID 映射逐实体恢复排序表，不能用一次 MoveToTop 整组代替指定顺序。WorkingDatabase 只在同步范围切换并恢复，不修改原始实体或打开临时文档。

XrefBlockVisualSession 复用自己创建的离屏设备。当前 2026 宿主 IsValid 不能作为完成依据，最多三轮核对视图、设备和再次读回的完整 BGRA32 数据，不设像素误差阈值；不稳定或非空内容意外得到空图时不接受匹配。无损压缩代表按来源编号顺序归组，未知来源不加入一致组。两个可靠内容组已确认不同优先不匹配，其他未知原因保留。

### 明确不完整的情况

- 动态定义／引用，不读取参数、动作或可见性，不触发动态求值。
- 三维实体、Region、Surface、网格、代理和未覆盖的原生／自定义类型；不恢复 BRep 引用。
- 循环或失效依赖、字段读取异常、未解释二进制／地址／扩展数据。
- 必要字体、图片等资源无法读取，或资源语义未完整覆盖。
- 非连续线型、Wipeout／文字背景遮罩、可能重叠的不同有效颜色／线宽内容、裁剪和不能确认的显示次序；当前后端不能可靠证明匹配。

匹配仅表示在规定视角、条件和分辨率下通过验证，不代表无限精度几何等价。原生测试发现离屏后端对非连续线型、Wipeout／文字背景遮罩、重叠异色内容排序不能可靠绘制，这些场景明确未验证；动态、三维、代理、循环、字段、字体缺失、渐变和无法解释的文字复合格式也未验证。当前实现尚不等同 CAD 的完整 DWG 比较。

## 报告与生命周期

最终报告为 `Result.csv`，每个跨图纸同名普通块一行：

```csv
块名称,dwgNo,结果
Valve,1/2/5,不匹配
Pump,1/3,匹配
```

dwgNo 去重后按数字升序以 / 连接，结果只保留三种：

| 结果 | 含义 |
| --- | --- |
| 匹配 | 全部相关来源完整通过指定视角、分辨率和有效外观核对 |
| 不匹配 | 已确认存在不同内容组；其他未知来源及原因保留在 LOG |
| 未验证 | 读取失败、比较不完整、取消或尚未执行，不能证明完整一致 |

独立匿名根及单来源块仍保留在名称统计中，不加入比较报告；无候选时只输出表头。不再创建 NormalBlockComparison.csv，也不登记或删除目录内的历史同名报告。

来源、内容分组、差异、SDK 错误、范围与完整性、准备／设备／绘制数量及耗时写入 LOG。差异 PNG 左侧红、右侧绿、相同区域灰；截图难辨认的颜色／线宽差异在图注和 LOG 列值。不保存所有匹配来源图像。每候选报告写入并刷新后，命令行立即输出符合／不符合／未验证；Result.csv 的三列和结果文字保持。

默认目录为文档目录下 `Pn3DKit\XrefBlockCheck\yyMMddHHmmss`。全部固定文件和逐图清单使用 CreateNew，CSV 为 UTF-8 BOM／RFC 4180／CRLF。目录选择保留 FILEDIA、C 和重名目录序号；固定文件冲突要求重选。

Esc、原图关闭／切换、来源失效或文件变化时停止。已完成结果反映读取时快照，剩余候选仅用内存记录“未验证”，具体停止原因保留在 LOG，不重新读取失效图纸。任一输出创建、写入、刷新或关闭故障停止后续处理。全部文件关闭后统一询问日志保留；完整且所有候选匹配或无候选默认 N，存在不匹配、未验证、扫描不完整、错误或中断默认 Y。无法安全询问则保留，只删除本批归属文件，不清理历史报告或用户文件。

不执行绑定、插入、重载、保存、动态更新或 Plant 写入，报告不模拟 Bind → Insert 的最终结果。

## 验证界限

离线测试验证完整像素、有效外观、编码、压缩归组、三态报告、取消和 PNG 归属／故障停止，不冒充原生绘制。授权 Plant 3D 原生用例覆盖颜色、线宽、文字、属性默认值、填充、标注、普通嵌套、双背景、共同视窗及未知保护；11 来源实际流程读出 684 条名称、103 候选，全部未验证，具体动态／克隆／来源范围原因见 artifacts/validation/0.1.34/。有限测试不等同整体准确性验收。
