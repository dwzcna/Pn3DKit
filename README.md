# Pn3DKit

**Pn3DKit 0.1.30** 是 AutoCAD／Plant 3D 2026 的工具插件，提供外部参照同名块冲突检查、Plant 位号与快速特性工具，以及项目图纸批量导出。

适用于 Windows x64。外部参照块检查只需当前 CAD 图纸；使用 Plant 属性、位号和项目导出功能时，需要相应 Plant 项目。

## 有哪些功能

| 命令 | 用途 |
| --- | --- |
| `CHECKPNTAG` | 检查一个部件的现有位号是否符合其格式和当前属性，显示差异 |
| `CHECKPNTAGBYCLASS` | 按类别检查当前图纸中的部件，生成文本日志和 CSV |
| `REBUILDPNTAGBYCLASS` | 预览并确认后，按类别更新当前图纸中 PnId 部件的位号 |
| `CHECKPROJECTPNTAGBYCLASS` | 按类别检查整个项目，包含未打开图纸 |
| `REBUILDPROJECTPNTAGBYCLASS` | 全项目预检后，选择打开图纸重建或仅提交项目数据 |
| `PNFASTPANEL` | 查看自定义 Plant 属性，统一编辑所选对象的共有可写属性 |
| `GETPNTAGFORMAT` | 查看一个部件采用的位号格式 |
| `EVALUATEPNTAG` | 为一个部件输入格式，计算该格式对应的位号 |
| `PNDWGEXPORT` | 将当前项目的 PnId 或 Piping 图纸批量导出为普通 DWG |
| `XREFBLOCKCHECK` | 在 Bind 的 Insert 合并前，检查主图和外参中的同名块定义冲突 |

位号检查生成对比结果，不主动写回目标位号或保存图纸；期望位号中的自动编号片段沿用现有 Tag。**SDK 求值可能按格式规则（如 `^`）更新项目序列字段，检查、求值及重建预检不保证无副作用。** 相关命令开始时提示一次，检查及重建日志也会记录此说明。


## Ribbon 入口

加载后，在 **Pn3D工具箱** 选项卡中使用三个分区：

| 分区 | 布局与入口 |
| --- | --- |
| 快速操作 | 左侧大按钮“PN快速特性”；右侧上下排列“评估元件位号”“获取位号格式” |
| 位号检查 | 第一行“检查元件位号”；第二行“检查本图位号／重建本图位号”；第三行“检查项目位号／重建项目位号” |
| 图纸操作 | 左侧“批量导出CAD”，右侧“外部参照检查块冲突”，均为大按钮 |

七个位号按钮使用 16 DIP 小图标和右侧中文文字，统一宽度 128 DIP；PN快速特性及批量导出CAD 保留大图标。检查在左、重建在右，Tooltip 显示完整命令、操作范围和必要提示。单对象命令保留预选；CAD 忙碌或批次运行时禁用入口，工作空间重载后自动恢复，不重复创建选项卡。

## 下载与加载

1. 在 [Releases](https://github.com/dwzcna/Pn3DKit/releases) 下载 DLL，或下载 ZIP 后解压。
2. 将 `Pn3DKit.dll` 放入 AutoCAD 的可信目录。
3. 在 Plant 3D 中执行 `NETLOAD`，选择该 DLL。
4. 打开 Plant 项目和图纸，即可使用命令。批量导出也可点击 **Pn3D工具箱 → 图纸操作 → 批量导出CAD**。

升级时先退出 CAD，替换 DLL，再重新启动并加载。已经加载的程序集不能在同一 CAD 会话中直接替换。


## PN快速特性

点击 Ribbon 的 **PN快速特性**，或执行 `PNFASTPANEL`，打开可停靠的 **Pn属性｜值** 表格。默认只有一个空白属性行：在左列输入 `Comment` 等属性名，按回车或离开单元格后读取；用“添加属性”“删除属性”调整行。

属性列始终可以输入，即使没有选择对象。简写 `Comment` 读取 `TargetObject.Comment`，也接受完整自身路径。本轮只处理 Plant 自身属性，不通过其他类别路径改写来源对象。

逐个确认所选对象的图纸、项目、字段可写且图层未锁定后，Comment、Area 等普通字段支持自身及继承的属性定义，满足权限时允许编辑；空备注也可输入，字段设置沿用当前类别的配置。普通字段不再被显示名称、排序等描述元数据或无关位号格式拦住。字段只读、系统维护、自动生成、表达式、获取规则、项目读写登记及批次状态仍会限制编辑；不能确认必要权限时显示只读原因。阀门 Size 等获取属性不解除获取关系、不修改管线等来源对象。Tag 继续采用专用登记及冲突校验，未确认安全条件时只读。

编辑值后**Enter 提交并停留当前单元格，Tab／Shift+Tab 提交并切换单元格，失焦只提交一次，Esc 撤销当前输入**。操作期间保留对象选择；面板输入及提交保持键盘焦点，离开面板后由 CAD 接管。提交前先核对全部目标的图纸、选择、路径、原值、权限和输入；任一预检失败时不写入任何对象。写入后逐项回读，实际失败立即停止后续对象，显示已更新、无需修改、失败、未执行及实际值，不假定项目数据已回滚。**不自动保存、不生成编号、不改变获取模式、不生成运行日志。**

“多种值”只是提示，未修改的 Enter 或失焦不会清空对象。输入新值后统一应用；明确按 Delete／Backspace 可清空允许为空的混合值。Tag 仍须通过项目及批内登记冲突检查，不生成新编号。右键菜单取消或未弹出后继续正常输入与提交。

面板跟随预选、选择和图纸变化；多选显示共同值或“多种值”；只有所有对象都含有该属性且分别允许编辑时，值格才开放输入。例如手动阀与流量计的 installed 都可写时可统一修改；任一对象的 Size 通过获取规则取得、只读，或任一设备不含 Size 时，整行保持只读。不同类别和不同当前值不阻止共有可写属性的编辑。属性存在但值为空时显示空白；确认元件不含该属性时显示 `--`。未选择、读取中或环境不可用时保持空白，原因可悬停查看；读取异常显示“读取失败”。不可编辑的值使用灰色文字及灰底，仍可选择复制，悬停查看全文和原因；恢复编辑权限后自动恢复正常颜色。表格采用更紧凑的行高。 右键菜单、禁用按钮统一跟随深浅主题，禁用项使用清晰的灰字灰底，菜单保留快捷键提示。

单选有效 Plant 对象并等待读取完成后，点击“检索属性”打开独立窗口。窗口显示属性路径（如 Area）及显示名称（如绘图区域），包含继承、自定义和只读字段；显示名称优先采用当前项目的本地化名称，再由 SDK 回退列配置，无有效名称时显示内部属性名，异常详情见提示。已有属性预勾选且不能取消；勾选其他属性后点“添加所选属性”，只追加缺失项，保留原有行和顺序。简写与 TargetObject 完整路径自动去重，取消不更改面板；新增行仍按实际权限开放编辑。无选择、多选、非 Plant 对象或忙碌时不可检索。

支持左右停靠、浮动、自动隐藏、深浅主题和高 DPI，沿用协调的蓝灰／灰白配色。大量选择分批读取，CAD 命令／批次忙碌或面板隐藏时暂停。末行输入并按 Enter 或失焦后自动补一行空白属性，保持当前焦点。右键“移除此属性行”或行内 Ctrl+D 只移除面板配置，不写入对象；底部添加按钮定位末尾空行。同一会话保留属性行配置，重启后恢复一个空行。真实 Comment 写入、原生面板对照、注释刷新和撤销仍待 CAD 复测。

## 检查外部参照的同名块冲突

执行 `XREFBLOCKCHECK`，统一确认日志目录后，检查主图、直接外参和按附着规则纳入的嵌套外参。主图尚未插入的命名块也参与；同名同内容归组，同名不同内容显示来源及具体差异。主图没有该块时，外参之间的差异也会报告，并提示绑定顺序风险。

命令不执行绑定、插入、重载或保存。已加载外参使用宿主数据，未加载文件只读读取；无法读取、代理对象或尚未完整解释的动态／三维数据明确标为“无法完整比较”。已经确认冲突时，仍显示冲突并保留未完成原因，不能把未知来源当作一致。

默认日志为 `文档\Pn3DKit\XrefBlockCheck\yyMMddHHmmss` 下的 `XrefBlockCheck.log` 和带 BOM 的 CSV，支持 FILEDIA、C 选择目录、Esc 中断及最后的日志保留询问。命令行列出前 20 个冲突，完整分组见报告。比较覆盖及当前限制见 [外部参照检查说明](docs/XrefBlockCheck.md)。真实 CAD 与实际 Bind → Insert 对照待复测。

## 检查一个部件的位号

先选中一个部件，再输入 `CHECKPNTAG`；也可以先执行命令，再选择部件并按回车。

插件使用该部件类别当前配置的位号格式，比较现有 Tag 和当前属性。例如：

```text
位号一致：PT-101
```

属性变化而位号尚未同步时，会显示：

```text
位号不符：现有 PT-101；按格式应为 PT-102
TargetObject.LoopNumber：Tag 中为 101，当前属性为 102
```

| 状态 | 含义 |
| --- | --- |
| 一致 | 现有位号符合格式和当前属性 |
| 不符 | 至少一个属性段需要更新，命令同时显示期望位号 |
| 无格式 | 部件类别未配置位号格式 |
| 无 Tag | 没有可检查的位号；Piping 会尝试读取 LineNumberTag |
| 临时 Tag | 位号以 `?` 开头，本次不重建 |
| 错误 | 格式、数据关联或字段拆分无法可靠处理，显示原因及可获得的 SDK 状态 |

期望位号中的自动编号片段沿用现有 Tag；这不保证 SDK 求值不会更新项目序列字段。SLINE 的管线组属性、阀门所在管线的属性与阀门自身属性会按各自上下文处理。无法可靠拆分现有位号时显示错误，不推测结果。

检查与重建预检对 N／NN／NNN 数字字段按当前属性值进行 SDK 格式化，保留自动编号及相邻文字。例如现有 `I-302H-102` 在 LoopNumber 为 302 时一致，改为 303 后期望为 `I-303H-102`；NNN 下的 2 显示为 002。非空数字无法格式化时报告“字段格式化失败”，显示属性路径、原值、格式及可获得的 SDK 错误，不生成缺号的期望位号。

## 按类别批量检查

执行 `CHECKPNTAGBYCLASS`，插件扫描**当前图纸模型空间**，列出有位号格式的类别及对象数量：

```text
1 - BallValve (12)
2 - CheckValve (5)
请选择类别编号 [如 1,3,5-7；*=全部] <0>:
```

- 输入 `1,3,5-7` 可选择多个类别和连续区间，重复编号会自动去重。
- 输入 `*` 检查全部列出的类别。
- 回车或输入 `0` 结束，不执行检查。
- 无效编号会说明原因并重新提示；按 Esc 可取消。

没有位号格式的类别会单独列为“已跳过”。检查不遍历块定义、外部参照或图纸空间，也不会打开项目中的其他图纸。

类别列表和未配置格式的提示采用项目设置的类别显示名称；未设置或无法读取名称时显示实际类名。列表按显示名称依当前系统区域规则升序排列，英文忽略大小写；显示名称相同时，再按实际类名和项目部分稳定排序。名称相同的不同类别仍分别列出，日志继续记录实际类名。

批量命令按当前图纸关联的数据行汇总实际类别，包含没有独立图形的 **PipeLineGroup（管线组）**。组按关联工艺管线纳入；有格式时可选择检查／重建，无格式时明确显示组数。工艺管线缺失组关联会报告异常，不自动创建或修复组。

SLINE（包括 Primary、Secondary 等子类）和管线组都可重建，可靠计算出的期望位号允许保留问号，空属性仍记录在日志中。保留自动编号，不补造缺失值。例如尺寸为空时，`SWR-12514?-?-不编号%%` 可按可靠的字段结果重建为 `SWR-12514?-.-不编号%%`。

选择管线组只更新组自身配置的 Tag，不改写 Service、LineNumber、NominalSize 或成员关系，也不自动重建未选择的 SLINE。预览列明成员、关联图纸及跨图纸共享范围；组先于成员处理，成员期望值变化时须重新预检。组没有自身句柄，使用真实数据行 ID 识别。

### 日志保存在哪里

选择类别后，统一确认一次日志目录，建议位置为：

```text
系统文档目录\Pn3DKit\TagCheck\yyMMddHHmmss
```

同一时间的目录已存在时，建议名称会追加 `_01`、`_02` 等序号。

- `FILEDIA=1`：命令行显示 `输出日志目录<建议路径> 或 [选择..(C)]:`。回车采用建议路径，输入 C 或点击“选择..(C)”打开文件夹选择器。
- `FILEDIA=0`：直接在命令行输入目录，回车采用建议路径。
- 直接写入确认的文件夹；已有同名日志时要求选择其他位置，不覆盖原文件。

文件夹中生成：

| 文件 | 内容 |
| --- | --- |
| `TagCheck.log` | 图纸、所选类别、起止时间、逐条检查结果和类别汇总 |
| `TagCheck.csv` | 项目部分、类别、数据行ID、句柄、现有Tag、期望Tag、状态、差异字段；可用 Excel 打开 |

检查过程中定期显示进度。Esc 中断后，已经写入的结果仍保留，日志标记“已中断”并统计未处理数量。切换到其他图纸或关闭原图时会停止，保留已完成日志并说明原因。命令行显示六种状态的类别汇总，以及前 20 条不符的位号和句柄；完整结果请查看日志。

## 按类别重建位号

当属性发生变化，现有位号需要同步时，执行 `REBUILDPNTAGBYCLASS`：

1. 图纸必须可写，并以读写方式加入当前 Plant 项目。
2. 按类别编号选择对象，方式与批量检查相同。回车或 0 结束。
3. 确认日志目录，默认在系统文档目录的 `Pn3DKit\TagRebuild\yyMMddHHmmss` 下。FILEDIA 和 C 选择目录方式与检查一致。
4. 查看“一致／可重建／不可重建／冲突”的类别汇总和前 20 条预览，例如 `PT-101 → PT-102（句柄 2A3F）`。完整预检已写入 CSV，可先用支持共享读取的查看器以只读方式核对。
5. 在“重建 N 个位号？”选择 **是／Y** 才开始写入，默认 **否／N**，保留预检日志并结束。
6. 写入后回读验证并刷新图纸，再询问是否 QSAVE。保存默认 **否／N**；选 Y 会保存本图所有修改，包括命令执行前的修改。

只更新 **PnId 的 Tag**，支持普通元件、SLINE 和管线组，保留现有自动编号。Piping 管线号、临时位号、无格式／无 Tag 或无法可靠检查的对象会跳过；普通元件期望值含问号时仍跳过，SLINE 和管线组允许保留可靠结果中的问号。

项目中已有占用、同批目标重复、两个位号互换，以及占用链（例如 A 要变成 B 的旧位号，即使 B 将改为空闲位号）都保守跳过全部涉及的所选对象。缺少位号注册表时会明确提示：冲突检查只能覆盖本图模型空间，无法排除其他图纸占用。预览后属性、格式、Tag 或占用发生变化时重新核对，避免按旧快照直接写入。

日志目录包含：

| 文件 | 内容 |
| --- | --- |
| `TagRebuild.log` | 图纸、类别、预检、确认、写入、撤销组、保存选择及结束汇总 |
| `TagRebuild.csv` | 项目部分、类别、数据行ID、句柄、原Tag、新Tag、动作、原因、差异字段；UTF-8 BOM |

CSV 采用**追加历史**：先预检再追加最终动作，以“项目部分＋数据行ID”的最后一条为准。同一数据行的多个图形只写一次；管线组自身句柄为空，成员及共享图纸范围见文本日志。已有同名日志不会覆盖。

Esc 会停止后续写入，保留已经完成的修改与日志。写入按一个 UNDO 组组织，但 **Plant 数据缓存是否随一次 UNDO 完整回退尚待实机确认，必要时请用日志恢复**。请先在项目副本上验证位号注释刷新、保存和撤销行为。


## 检查与重建整个项目

`CHECKPROJECTPNTAGBYCLASS` 检查当前项目实际使用的元件和管线组，包含未打开的图纸。类别列表显示目标数和关联图纸数；输入编号、范围或 `*`，回车／0 结束。共享数据行只统计一次。检查不主动打开图纸、写回目标位号或保存图纸；SDK 求值可能更新项目序列字段，不保证项目数据完全不变。

`REBUILDPROJECTPNTAGBYCLASS` 对全项目先做位号预检（SDK 求值可能更新序列字段），只更新 PnId 的 Tag（含 SLINE 和管线组），Piping 管线号跳过。预览列出位号变化和需要重建的完整图纸清单，CSV 可先以只读方式核对。冲突按项目注册键检查；没有注册表时使用完整项目索引，索引不完整则禁止相关写入。 打开图纸重建时，遇到只读图纸记录跳过并继续；工具打开的干净图纸在确认没有待提交缓存后关闭，原先打开的图纸保持打开。

```text
重建方式 [打开图纸重建(Y)/仅重建项目数据(N)/取消(C)] <N>:
```

**回车默认 N，会修改并提交项目数据。** 请选择适合的方式：

- **N：仅项目数据**。不打开 DWG、不 QSAVE、不刷新图纸。已有待提交项目修改时停止，避免代为提交原有修改；提交异常或回读不明也停止，不全局拒绝修改。图纸注释可能尚未刷新，当前 DWG 的 UNDO 不保证恢复项目数据，请按日志恢复。
- **Y：打开图纸重建**。先统一选择是否保存，默认 N。逐图重新校验、写入、回读及刷新，每图独立撤销组。共享行只写一次，其他关联图纸验证并刷新。选择保存时 QSAVE 包括原有修改；不保存时全部修改图纸保持打开。原先打开的图纸始终保留，工具打开的图纸只在无图纸修改且无待提交项目数据时关闭。不承诺跨图纸一次撤销。
- **C／Esc：取消**。保留预检和已完成记录，不继续写入。

日志目录沿用 FILEDIA 和 `[选择..(C)]`，直接写入确认的文件夹：

| 命令 | 建议目录（系统文档目录下） | 文件 |
| --- | --- | --- |
| 项目检查 | Pn3DKit/ProjectTagCheck/yyMMddHHmmss | ProjectTagCheck.log、ProjectTagCheck.csv |
| 项目重建 | Pn3DKit/ProjectTagRebuild/yyMMddHHmmss | ProjectTagRebuild.log、ProjectTagRebuild.csv |

同秒目录建议追加序号；不覆盖同名文件。CSV 为 UTF-8 BOM，包含项目部分、类别、数据行ID、所有关联图纸、句柄及结果。重建保留预检和最终动作的追加历史，以“项目部分＋数据行ID”的最后一条为准。项目变化、Esc 或日志故障会停止并保留已完成内容。

## 查看格式与计算位号

`GETPNTAGFORMAT` 支持预选或执行后单选，显示部件类别、格式名称及完整格式表达式。非 Plant 部件或未配置格式时会说明原因。

`EVALUATEPNTAG` 采用相同选择方式，随后请求输入格式，例如：

```text
#(+TargetObject.Type)-#(+TargetObject.Area)#(TargetObject.Number^NN)
```

命令输出计算得到的位号。属性明确缺失时显示对应格式片段，例如“所选目标不含属性 #(+TargetObject.Area)”。查询和计算均不向部件赋号或保存图纸。

## 批量导出普通 DWG

执行 `PNDWGEXPORT`，或点击 Ribbon 中的“批量导出CAD”，依次完成：

1. 选择 **P - PnId** 或 **D - Piping**。默认匹配当前图纸类型，未匹配时默认 PnId。
2. 选择导出前是否保存修改。**Yes／Y** 为默认值；**No／N** 跳过有未保存修改的图纸。
3. 统一确认输出目录。FILEDIA 的回车、C 选择和命令行输入方式与检查日志相同。
4. 选择 DWG 版本：**2007、2010、2013、2018**，默认 **2013**。
5. 等待导出，查看逐图进度、统计及输出目录中的 `Export.log`。

建议目录为系统文档目录下的 `Pn3DKit\Export\yyMMddHHmmss`。插件直接使用确认的目录，保留项目图纸层次；不会逐个文件再询问保存位置，也不会覆盖源图或已有正式输出。

**Yes 会通过 QSAVE 保存有修改的源图，后续取消不会撤销保存。** 保存失败或保存后仍有修改的图纸不导出；已保存的只读图纸允许导出。开始前请备份项目。

原来打开的图纸保持打开。取消、导出状态不明确或发现新修改时，可能保留工具打开的图纸及临时文件，请根据提示检查现场。执行时不要切换项目、图纸或启动其他命令。


## 批次结束后保留日志

批量导出、外参块检查、当前页及项目级的检查和重建，在处理及保存结束后统一询问：

```text
是否保留本批日志文件？[是(Y)/否(N)] <N或Y>:
```

- 全部检查一致、重建已更新或因一致正常跳过、导出全部成功时，默认 **N**。
- 发现不符、无 Tag、临时 Tag、错误、冲突、其他跳过或未完成时，默认 **Y**；扫描异常、取消、保存或日志故障也建议保留。
- 扫描时正常过滤无格式类别、用户选择不保存图纸，不单独算错误。回车采用显示的默认值，也可明确选 Y 或 N；Esc 保留日志。
- 选 N 清理本批日志、CSV／JSON 报告及已结束命令的内部诊断文件。重建日志含原 Tag 和新 Tag，需要按日志恢复时请选择 Y。
- 不删除源图、导出 DWG、临时 DWG、未结束操作的现场文件或目录中的其他文件。只清理本批创建且已为空的目录。
- 当前无法安全询问或操作状态不明时保留文件；清理失败会显示实际剩余路径。

默认目录统一在系统文档目录的 **Pn3DKit** 文件夹内，按 Export、XrefBlockCheck、TagCheck、TagRebuild、ProjectTagCheck、ProjectTagRebuild 分类。自选目录仍直接使用，历史目录不会迁移或清理。

## 常见提示

- **没有当前 Plant 项目**：先在 Plant 3D 中打开项目和图纸。
- **不是可识别的 Plant 部件**：请选择当前项目中有数据关联的部件。
- **无法可靠拆分位号**：格式的相邻字段或现有 Tag 无法明确对应；请核对格式和属性，SDK 求值仍可能按格式规则更新序列字段。
- **目录已有日志**：选择其他文件夹，避免覆盖已有报告。
- **更新后仍显示旧版本**：退出 CAD，确认替换了正确的 DLL，再重新加载。

构建和离线策略验证不能代替真实 CAD 验收。位号重建、自动编号片段保持、注释刷新、Esc、Plant 缓存撤销、图纸导出完整性及 SDK 序列字段副作用仍需在项目副本中复测。

源码构建、SDK 配置和自动发布说明见 [开发与构建](docs/Building.md)。
