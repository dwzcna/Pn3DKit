# Pn3DKit 0.1.31

用于 AutoCAD／Plant 3D 2026、Windows x64 的工具插件。外参块检查不要求 Plant 项目，其他 Plant 功能需要相应环境。


## Ribbon 入口

加载后，在 **Pn3D工具箱** 选项卡中使用三个分区：

| 分区 | 布局与入口 |
| --- | --- |
| 快速操作 | 左侧大按钮“PN快速特性”；右侧上下排列“评估元件位号”“获取位号格式” |
| 位号检查 | 第一行“检查元件位号”；第二行“检查本图位号／重建本图位号”；第三行“检查项目位号／重建项目位号” |
| 图纸操作 | 左侧“批量导出CAD”，右侧“外部参照检查块冲突”，均为大按钮 |

七个位号按钮使用 16 DIP 小图标和右侧中文文字，统一宽度 128 DIP；PN快速特性及批量导出CAD 保留大图标。检查在左、重建在右，Tooltip 显示完整命令、操作范围和必要提示。单对象命令保留预选；CAD 忙碌或批次运行时禁用入口，工作空间重载后自动恢复，不重复创建选项卡。

## 安装

将 Pn3DKit.dll 放在 CAD 可信目录，在 Plant 3D 中执行 NETLOAD 加载。打开 Plant 项目和图纸后使用命令。升级时先退出 CAD，再替换并重新加载 DLL。

## 功能

| 命令 | 功能 |
| --- | --- |
| CHECKPNTAG | 检查一个部件的现有位号，显示期望位号和属性差异 |
| CHECKPNTAGBYCLASS | 按类别检查当前图纸模型空间，生成 TagCheck.log 和 TagCheck.csv |
| REBUILDPNTAGBYCLASS | 预检并确认后按类别更新 PnId 部件位号，生成重建日志与 CSV |
| CHECKPROJECTPNTAGBYCLASS | 按类别检查整个项目，包含未打开图纸 |
| REBUILDPROJECTPNTAGBYCLASS | 全项目预检后选择逐图重建或提交项目数据 |
| PNFASTPANEL | 查看自定义 Plant 属性，统一编辑所选对象的共有可写属性 |
| GETPNTAGFORMAT | 查看一个部件采用的位号格式 |
| EVALUATEPNTAG | 输入格式，计算所选部件对应的位号 |
| PNDWGEXPORT | 将项目 PnId／Piping 图纸批量导出为普通 AutoCAD DWG |
| XREFBLOCKCHECK | 检查主图及外参的同名块定义冲突，供 Bind 的 Insert 合并前核对 |

CHECKPNTAG、GETPNTAGFORMAT、EVALUATEPNTAG 均支持先选择部件再执行命令，也支持执行后选择一个部件、回车确认。批量检查按当前图纸扫描，不使用预选范围。

检查与重建预检按当前属性值格式化 N／NN／NNN 数字段，保留自动编号及相邻文字。例如 `I-302H-102` 的 LoopNumber 改为 303 后期望为 `I-303H-102`，NNN 下的 2 显示为 002。非空数字格式化失败时报告属性、原值、格式和可获得的 SDK 错误，不生成缺少编号的期望位号，也不进入重建写入。

类别列表和未配置格式的提示采用项目设置的类别显示名称；未设置或无法读取名称时显示实际类名。列表按显示名称依当前系统区域规则升序排列，英文忽略大小写；显示名称相同时，再按实际类名和项目部分稳定排序。名称相同的不同类别仍分别列出，日志继续记录实际类名。

批量命令按当前图纸关联的数据行汇总实际类别，包含没有独立图形的 **PipeLineGroup（管线组）**。组按关联工艺管线纳入；有格式时可选择检查／重建，无格式时明确显示组数。工艺管线缺失组关联会报告异常，不自动创建或修复组。

SLINE（包括 Primary、Secondary 等子类）和管线组都可重建，可靠计算出的期望位号允许保留问号，空属性仍记录在日志中。保留自动编号，不补造缺失值。例如尺寸为空时，`SWR-12514?-?-不编号%%` 可按可靠的字段结果重建为 `SWR-12514?-.-不编号%%`。

选择管线组只更新组自身配置的 Tag，不改写 Service、LineNumber、NominalSize 或成员关系，也不自动重建未选择的 SLINE。预览列明成员、关联图纸及跨图纸共享范围；组先于成员处理，成员期望值变化时须重新预检。组没有自身句柄，使用真实数据行 ID 识别。


## 外部参照检查块冲突

执行 `XREFBLOCKCHECK`，或点击“图纸操作”中的同名按钮，确认日志目录后先收集主图及直接／可传播嵌套外参的块名称，只深入比较跨来源同名的非匿名块。同名定义按内容归组，列出差异与来源；主图未插入的块、仅外参之间的冲突也参与。无法完整读取或解释的内容不会判为一致。

匿名块跨图同名时直接列为“匿名块同名，未比较”，不计为已确认内容冲突；命名父块内部的匿名依赖仍参与完整比较。唯一名称不独立读取内容，仅按图纸汇总数量，不逐块写入 CSV。报告显示阶段耗时及读取数量；大量定义都跨图同名时仍需要完整比较。出现匿名未比较项、冲突、不完整、错误或中断时，日志保留默认 Y。

不绑定、不插入、不重载、不保存；已加载数据使用宿主当前数据库，未加载文件旁路只读读取。支持 Esc；切换或关闭原图停止。默认目录为 `文档\Pn3DKit\XrefBlockCheck\yyMMddHHmmss`，生成逐条刷新的 `XrefBlockCheck.log` 和 UTF-8 BOM CSV；FILEDIA 和 C 选择目录沿用现有流程，结束时询问保留日志。

动态原生 EvalGraph、约束子实体／专有参数、部分曲面 UV 修剪与子实体外观、网格棱折／材质和代理数据仍可能或必然标记为无法完整比较；报告会具体列出原因。报告不保证模拟最终 Bind → Insert 行为。覆盖与限制：https://github.com/dwzcna/Pn3DKit/blob/main/docs/XrefBlockCheck.md 。真实 CAD 对照待复测。

## PN快速特性

点击 Ribbon 的 **PN快速特性**，或执行 `PNFASTPANEL`，打开可停靠的 **Pn属性｜值** 表格。默认只有一个空白属性行：在左列输入 `Comment` 等属性名，按回车或离开单元格后读取；用“添加属性”“删除属性”调整行。

属性列始终可以输入，即使没有选择对象。简写 `Comment` 读取 `TargetObject.Comment`，也接受完整自身路径。本轮只处理 Plant 自身属性，不通过其他类别路径改写来源对象。

逐个确认所选对象的图纸、项目、字段可写且图层未锁定后，Comment、Area 等普通字段支持自身及继承的属性定义，满足权限时允许编辑；空备注也可输入，字段设置沿用当前类别的配置。普通字段不再被显示名称、排序等描述元数据或无关位号格式拦住。字段只读、系统维护、自动生成、表达式、获取规则、项目读写登记及批次状态仍会限制编辑；不能确认必要权限时显示只读原因。阀门 Size 等获取属性不解除获取关系、不修改管线等来源对象。Tag 继续采用专用登记及冲突校验，未确认安全条件时只读。

编辑值后**Enter 提交并停留当前单元格，Tab／Shift+Tab 提交并切换单元格，失焦只提交一次，Esc 撤销当前输入**。操作期间保留对象选择；面板输入及提交保持键盘焦点，离开面板后由 CAD 接管。提交前先核对全部目标的图纸、选择、路径、原值、权限和输入；任一预检失败时不写入任何对象。写入后逐项回读，实际失败立即停止后续对象，显示已更新、无需修改、失败、未执行及实际值，不假定项目数据已回滚。**不自动保存、不生成编号、不改变获取模式、不生成运行日志。**

“多种值”只是提示，未修改的 Enter 或失焦不会清空对象。输入新值后统一应用；明确按 Delete／Backspace 可清空允许为空的混合值。Tag 仍须通过项目及批内登记冲突检查，不生成新编号。右键菜单取消或未弹出后继续正常输入与提交。

面板跟随预选、选择和图纸变化；多选显示共同值或“多种值”；只有所有对象都含有该属性且分别允许编辑时，值格才开放输入。例如手动阀与流量计的 installed 都可写时可统一修改；任一对象的 Size 通过获取规则取得、只读，或任一设备不含 Size 时，整行保持只读。不同类别和不同当前值不阻止共有可写属性的编辑。属性存在但值为空时显示空白；确认元件不含该属性时显示 `--`。未选择、读取中或环境不可用时保持空白，原因可悬停查看；读取异常显示“读取失败”。不可编辑的值使用灰色文字及灰底，仍可选择复制，悬停查看全文和原因；恢复编辑权限后自动恢复正常颜色。表格采用更紧凑的行高。 右键菜单、禁用按钮统一跟随深浅主题，禁用项使用清晰的灰字灰底，菜单保留快捷键提示。

单选有效 Plant 对象并等待读取完成后，点击“检索属性”打开独立窗口。窗口显示属性路径（如 Area）及显示名称（如绘图区域），包含继承、自定义和只读字段；显示名称优先采用当前项目的本地化名称，再由 SDK 回退列配置，无有效名称时显示内部属性名，异常详情见提示。已有属性预勾选且不能取消；勾选其他属性后点“添加所选属性”，只追加缺失项，保留原有行和顺序。简写与 TargetObject 完整路径自动去重，取消不更改面板；新增行仍按实际权限开放编辑。无选择、多选、非 Plant 对象或忙碌时不可检索。

支持左右停靠、浮动、自动隐藏、深浅主题和高 DPI，沿用协调的蓝灰／灰白配色。大量选择分批读取，CAD 命令／批次忙碌或面板隐藏时暂停。末行输入并按 Enter 或失焦后自动补一行空白属性，保持当前焦点。右键“移除此属性行”或行内 Ctrl+D 只移除面板配置，不写入对象；底部添加按钮定位末尾空行。同一会话保留属性行配置，重启后恢复一个空行。真实 Comment 写入、原生面板对照、注释刷新和撤销仍待 CAD 复测。

## 按类别重建位号

执行 REBUILDPNTAGBYCLASS，选择当前模型空间的类别和日志目录，查看预检汇总及位号变化后，再明确选择 Y 执行。重建确认默认 N；写完后的 QSAVE 保存确认也默认 N。保存会包含图纸中已有的其他修改。

仅处理可写、以读写方式加入当前项目的图纸，只写 PnId.Tag，支持 SLINE 和管线组并保留自动编号。Piping、无格式、无 Tag、临时 Tag、SDK 错误及普通元件含问号的期望 Tag 均跳过。占用、重号、互换和占用链保守跳过；缺少注册表时提示本图回退索引的范围及完整性。

日志默认位于“系统文档目录/Pn3DKit/TagRebuild/yyMMddHHmmss”，支持与检查相同的 FILEDIA 和 C 目录选择。TagRebuild.log 记录预检、确认、写入及保存；TagRebuild.csv 带 UTF-8 BOM，列为项目部分、类别、数据行ID、句柄、原Tag、新Tag、动作、原因、差异字段。两文件均不覆盖。

CSV 是追加历史，以同一项目部分及数据行ID最后一条为最终结果。组自身句柄为空，成员范围见文本日志。Esc 保留已完成修改，剩余项记录未执行；写入后回读验证并刷新图纸。

写入用一个 UNDO 组组织，但 Plant 数据缓存能否随 UNDO 完整回退尚待 CAD 实机确认，必要时请用日志恢复。请先使用项目副本验证位号注释、自动编号、撤销和保存。真实 CAD 的写入、缓存撤销和注释行为仍需在项目副本验证。

## 检查位号

CHECKPNTAG 显示例如：

```text
位号不符：现有 PT-101；按格式应为 PT-102
TargetObject.LoopNumber：Tag 中为 101，当前属性为 102
```

结果分为一致、不符、无格式、无 Tag、临时 Tag、错误。临时 Tag 以 ? 开头。检查结果沿用现有自动编号，不主动写回目标位号或保存图纸；SDK 求值可能更新项目序列字段，不保证无副作用。无法可靠拆分时显示错误原因及可获得的 SDK 状态。

CHECKPNTAGBYCLASS 列出类别及数量后，可输入 1,3,5-7 或 *（全部）；重复去重，回车或 0 不执行。无格式类别单独提示跳过。

选择类别后确认日志目录，默认位于系统“文档”下的 Pn3DKit/TagCheck/yyMMddHHmmss。FILEDIA=1 时回车采用建议目录，输入 C 或点击“选择..(C)”浏览文件夹；FILEDIA=0 时在命令行输入路径。已有同名日志时需更换目录。

TagCheck.log 记录参数、逐条结果及类别汇总。TagCheck.csv 可用 Excel 打开，包含项目部分、类别、数据行ID、句柄、现有Tag、期望Tag、状态、差异字段。逐条保存结果，Esc 中断保留已写内容；切换图纸或关闭原图时停止并说明原因。命令行显示六种状态统计和前 20 条不符，完整明细见日志。

## 查看与计算

GETPNTAGFORMAT 显示类别、格式名称和表达式。EVALUATEPNTAG 在选择后请求输入表达式，例如：

```text
#(+TargetObject.Type)-#(+TargetObject.Area)#(TargetObject.Number^NN)
```

计算结果只显示在命令行，不向部件赋号；属性明确缺失时会显示对应片段。

## 批量导出 CAD

点击“Pn3D工具箱 → 图纸操作 → 批量导出CAD”或执行 PNDWGEXPORT，依次选择 PnId／Piping、是否保存修改、输出目录及 DWG 版本。支持 2007、2010、2013、2018，默认 2013。

目录在批次前只确认一次，直接写入确认的文件夹，并保留项目图纸层次。FILEDIA 的回车／C／命令行方式与检查日志一致。默认建议 系统文档目录/Pn3DKit/Export/yyMMddHHmmss；根目录 Export.log 保存导出日志。

Yes／Y 会通过 QSAVE 保存有修改的源图，取消不会撤销保存；No／N 跳过有修改图纸。保存失败或仍有修改时不导出，已保存只读图纸允许导出。请先备份项目。

不覆盖源图或已有正式输出。取消或状态不明确时，可能保留工具打开的图纸和临时文件，请根据提示检查现场。执行时不要切换项目、图纸或启动其他命令。


## 检查与重建整个项目

`CHECKPROJECTPNTAGBYCLASS` 检查当前项目实际使用的元件和管线组，包含未打开的图纸。类别列表显示目标数和关联图纸数；输入编号、范围或 `*`，回车／0 结束。共享数据行只统计一次。检查不主动打开图纸、写回目标位号或保存图纸；SDK 求值可能更新项目序列字段，不保证项目数据完全不变。

`REBUILDPROJECTPNTAGBYCLASS` 对全项目先做位号预检（SDK 求值可能更新序列字段），只更新 PnId 的 Tag（含 SLINE 和管线组），Piping 管线号跳过。预览列出位号变化和需要重建的完整图纸清单，CSV 可先以只读方式核对。冲突按项目注册键检查；没有注册表时使用完整项目索引，索引不完整则禁止相关写入。 打开图纸重建时，遇到只读图纸记录跳过并继续；工具打开的干净图纸在确认没有待提交缓存后关闭，原先打开的图纸保持打开。

```text
重建方式 [打开图纸重建(Y)/仅重建项目数据(N)/取消(C)] <N>:
```

**回车默认 N，会修改并提交项目数据。** 请选择适合的方式：

- **N：仅项目数据**。不打开 DWG、不 QSAVE、不刷新图纸。已有待提交项目修改时停止，避免代为提交原有修改；提交异常或回读不明也停止，不全局拒绝修改。图纸注释可能尚未刷新，当前 DWG 的 UNDO 不保证恢复项目数据，请按日志恢复。
- **Y：打开图纸重建**。先统一选择是否保存，默认 N。逐图重新校验、写入、回读及刷新，每图独立撤销组。共享行只写一次，其他关联图纸验证并刷新。选择保存时 QSAVE 包括原有修改；不保存时全部修改图纸保持打开。原先打开的图纸始终保留，工具打开的图纸只在无图纸修改且无待提交项目数据时关闭。不承诺跨图纸一次撤销。
- **C／Esc：取消**。保留预检和已完成记录，不继续写入。

日志目录沿用 FILEDIA 和 `[选择..(C)]`，直接写入确认的文件夹：

| 命令 | 建议目录（系统文档目录下） | 文件 |
| --- | --- | --- |
| 项目检查 | Pn3DKit/ProjectTagCheck/yyMMddHHmmss | ProjectTagCheck.log、ProjectTagCheck.csv |
| 项目重建 | Pn3DKit/ProjectTagRebuild/yyMMddHHmmss | ProjectTagRebuild.log、ProjectTagRebuild.csv |

同秒目录建议追加序号；不覆盖同名文件。CSV 为 UTF-8 BOM，包含项目部分、类别、数据行ID、所有关联图纸、句柄及结果。重建保留预检和最终动作的追加历史，以“项目部分＋数据行ID”的最后一条为准。项目变化、Esc 或日志故障会停止并保留已完成内容。


## 批次结束后保留日志

批量导出、外参块检查、当前页及项目级的检查和重建，在处理及保存结束后统一询问：

```text
是否保留本批日志文件？[是(Y)/否(N)] <N或Y>:
```

- 全部检查一致、重建已更新或因一致正常跳过、导出全部成功时，默认 **N**。
- 发现不符、无 Tag、临时 Tag、错误、冲突、其他跳过或未完成时，默认 **Y**；扫描异常、取消、保存或日志故障也建议保留。
- 扫描时正常过滤无格式类别、用户选择不保存图纸，不单独算错误。回车采用显示的默认值，也可明确选 Y 或 N；Esc 保留日志。
- 选 N 清理本批日志、CSV／JSON 报告及已结束命令的内部诊断文件。重建日志含原 Tag 和新 Tag，需要按日志恢复时请选择 Y。
- 不删除源图、导出 DWG、临时 DWG、未结束操作的现场文件或目录中的其他文件。只清理本批创建且已为空的目录。
- 当前无法安全询问或操作状态不明时保留文件；清理失败会显示实际剩余路径。
